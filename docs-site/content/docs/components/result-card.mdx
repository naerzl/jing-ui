---
title: Result Card
description: 成功、警告、错误和信息的整块结果反馈。
---

## 安装

```bash
pnpm dlx shadcn@latest add naerzl/jing-ui/result-card
```

## 使用方法

```tsx
<ResultCard
  variant="success"
  title="创建完成"
  description="可以继续配置组件。"
/>
```

`title` 必填；`variant` 为 `success`（默认）、`warning`、`danger`、`info`；`description`、`icon`、`children`、`className` 可选。色值读取宿主的 `--success`、`--warning`、`--destructive`、`--info`，并提供回退值。迁入时将状态颜色映射到可切换的语义变量。
