---
title: Counted Input
description: 带字数统计及可选单位后缀的输入框，组合官方 shadcn Input。
---

## 安装

```bash
pnpm dlx shadcn@latest add naerzl/jing-ui/counted-input
```

## 使用方法

```tsx
<CountedInput maxLength={24} placeholder="输入名称" />
<CountedInput type="text" unit="kg" maxLength={12} aria-label="重量" />
```

`CountedInputProps` 继承 `Input` 的常规属性，增加 `unit?: string` 和 `showCount?: boolean`。传入 `maxLength` 时默认显示计数；可传 `showCount={false}` 隐藏。支持受控 `value` 和非受控 `defaultValue`。`className` 作用于外层容器，输入框宽度随容器变化。
