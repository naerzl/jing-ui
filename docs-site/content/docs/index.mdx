## 开始使用

在已经配置 shadcn 的项目中，复制组件文档里的安装命令即可开始。组件会安装到你的项目目录，依赖项由 CLI 一并带入。

安装后可以直接调整样式与交互。主题色通过语义 CSS 变量设置，支持浅色和深色模式。

## 推荐阅读

- [组件目录](/docs/components/)：按用途查找组件，直接查看预览、用法和属性。
- [主题与颜色](/docs/theming/)：把组件调整为你的产品风格。
- [新增组件](/docs/contributing/)：补充源码、示例和文档后加入分发清单。
