# 文档界面设计约定

面向安装和定制 React 组件的开发者。阅读路径为：找到组件 → 试用交互 → 复制用法 → 查询属性。

## 视觉令牌

- 阅读底色：冷白 `#fcfcfd`。
- 正文：石墨 `#232730`；次要文字：灰蓝 `#687080`。
- 分隔线：雾灰 `#e5e8ee`；辅助面：`#f3f5f8`。
- 默认主色：钴蓝 `#4561df`，沿用橘红、森林绿、紫罗兰三套可选主色。
- 深色底色：`#13151b`，表面：`#1b1e26`。
- 西文字体：Geist；中文：苹方 / 微软雅黑；代码：Geist Mono。

## 布局

桌面保留 Fumadocs 的导航、正文和本页目录，增加全宽轻量顶栏。正文左对齐，组件预览占据主要阅读宽度。移动端由 Fumadocs 侧栏抽屉负责导航。

```text
品牌 / 文档       组件目录       主题色 · 明暗 · GitHub
───────────────────────────────────────────────────
开始使用      组件名称                        本页目录
表单输入      说明与源码链接                  安装
数据展示      ┌ 预览 / 代码 ── 宽度 · 重置 ┐  用法
状态反馈      │      真实可交互组件         │  属性
业务组件      └───────────────────────────┘
              安装命令 → 使用示例 → Props
```

## 组件预览

文档站通过 iframe 嵌入现有 React 18 / Tailwind 3 的预览入口。预览与组件演示站复用同一份示例；主题、主色和内容高度通过验证来源的消息同步。代码页签显示同一份示例目录中的用法。

## 设计复核

删除首版的大号衬线营销标题、无实际含义的编号和全大写标签。品牌识别集中在几何标记与主色；阅读区域减少装饰，预览中的真实交互作为主要视觉内容。为浅色、深色、窄屏、加载、复制失败和预览失败提供明确状态。
